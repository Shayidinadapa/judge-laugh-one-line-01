This program writes one line to `/output/entry.txt`:

> `My shadow quit on a cloudy day — tired of following someone who never knows where they're going.`

## Run it

```sh
node main.ts
```

`main.ts` validates the line (1–200 characters, one line, non-blank, no control characters) and writes it to `MAKEFUN_OUTPUT_DIR` (or `OUTPUT_DIR`, default `/output`).
